# Security Policy

This repository is a Linux-focused fork of
[CrealityOfficial/CrealityPrint](https://github.com/CrealityOfficial/CrealityPrint).
It mainly carries build and runtime fixes for Linux on top of upstream releases.

## Reporting a vulnerability

Please report security issues **privately**, not as a public issue:

- Use GitHub's [private vulnerability reporting](https://github.com/Arm4g3ddon/CrealityPrint/security/advisories/new)
  on this repository ("Security" tab -> "Report a vulnerability").

Please include what an attacker could do with the issue, and the steps to
reproduce it. You will get an acknowledgement as soon as the report is seen;
since this is a spare-time fork, please allow for some delay.

## Scope

- Issues in the Linux-specific patches carried here belong in this repository.
- Issues in CrealityPrint itself, in the printer firmware, or in Creality's
  cloud services affect upstream and should go to Creality. Note that upstream's
  own `SECURITY.md` still names the OrcaSlicer maintainer's private mail address,
  inherited from the original fork, so that contact does not reach Creality.
